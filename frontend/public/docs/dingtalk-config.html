钉钉对接配置说明

按本文操作后，员工可在签到页用钉钉扫码登录，系统可推送工作消息、同步通讯录（需权限），并对接 OA 审批（可选）

开始前准备：
1. 使用钉钉企业管理员账号操作（创建应用、开权限都要管理员）
2. 在 IM 配置页顶部记下你的租户 ID（下文用 {租户ID} 表示，例如 1）
3. 系统访问地址固定为 https://meeting.sisuu.com

一、配置完成后能实现什么

功能需要填哪些项
会议室 PAD / 签到页「钉钉登录」CorpId、AppKey、AppSecret、AgentId（并配置重定向 URL）
预定成功、审批结果等工作消息同上 + 通知设置选「钉钉工作消息」+ 通讯录权限
预定走钉钉 OA 审批再加：审批流程 Code、事件回调 Token/AESKey
群机器人查会议室（可选）事件回调 Token/AESKey + 机器人回调地址

二、IM 配置页字段对照（填什么、从哪来）

本系统字段是否必填在钉钉哪里找
钉钉企业 CorpId 必填 钉钉管理后台 → 设置 → 企业信息 → CorpId
应用 AppKey 必填 钉钉开放平台 → 应用开发 → 企业内部应用 → 你的应用 → 凭证与基础信息 → AppKey（或 Client ID，填到 AppKey 栏）
应用 AppSecret 必填 同上 → AppSecret（或 Client Secret），点击「查看」后复制
应用 AgentId 必填 应用详情页 → AgentId（纯数字）
审批流程 Code 选填 只有「预定需钉钉审批」才填。管理后台 → 工作台 → OA审批 → 模板详情 URL 里 processCode=PROC-xxxx 的值
回调 Token 配回调时必填 在开放平台「事件订阅」里自己设定一串字符，钉钉和本系统填完全相同的值
回调 EncodingAESKey 配回调时必填 事件订阅里点「生成 EncodingAESKey」，复制到钉钉和本系统（两边一致）

三、在钉钉开放平台创建应用

1 登录并创建应用

  1. 打开 钉钉开放平台（旧版入口 open.dingtalk.com 也会跳转）
  2. 进入 应用开发 → 企业内部应用 → 创建应用
  3. 名称建议：会议室预定；上传图标；创建完成后进入应用详情

2 复制 AppKey、AppSecret、AgentId

在应用详情 → 凭证与基础信息，把三项复制到 IM 配置页对应输入框。

3 配置重定向 URL（扫码登录必做）

在应用详情 → 开发配置 → 安全设置（或「登录与分享」），添加以下重定向/回调地址（域名需为 meeting.sisuu.com）：

  • Web 登录回调：https://meeting.sisuu.com/api/oauth/callback/dingtalk?tenant_id={租户ID}
  • 签到页回调（可填前缀或通配）：https://meeting.sisuu.com/checkin/
员工扫 PAD 二维码签到时，会跳转到 /checkin/... 页面，所以这条地址必须加白名单，否则扫码后报「redirect_uri 不合法」。

4 申请接口权限

应用详情 → 权限管理 → 搜索并开通（名称可能略有差异，按关键字搜）：

  • 通讯录：部门信息读、成员信息读、成员详情读
  • 根据手机号获取成员基本信息（用于账号与钉钉用户自动匹配）
  • 工作通知 / 企业会话消息发送（发预定提醒、审批通知）
  • OA 审批：审批实例写、审批实例读（仅在使用钉钉审批时）

申请后需企业管理员在管理后台 同意授权，权限才会生效。

5 配置事件订阅（使用 OA 审批时必做）

  1. 应用详情 → 事件订阅（或「事件与回调」）
  2. 请求网址 URL 填：
    https://meeting.sisuu.com/api/callback/approval/dingtalk?tenant_id={租户ID}
  3. 设置 Token 和 EncodingAESKey（可点自动生成）
  4. 把相同的 Token、EncodingAESKey 填回本系统 IM 配置页
  5. 订阅事件：勾选 审批实例状态变更（bpms_instance_change 等审批相关事件）
  6. 保存并验证 URL 通过

6 创建 OA 审批模板（可选）

  1. 钉钉管理后台 → 工作台 → OA审批 → 创建自定义模板
  2. 发布模板后，从浏览器地址栏复制 processCode= 后面的值（形如 PROC-XXXX）
  3. 填到 IM 配置页「审批流程 Code」

7 发布应用

  1. 开放平台 → 应用详情 → 版本管理与发布
  2. 创建版本并发布，可见范围选 全部员工

四、在本系统保存配置

  1. 打开 IM 配置 → 钉钉 标签
  2. 打开「启用」开关
  3. 按上表填写各项 → 点击 保存配置
  4. 切换到 通知设置，若要用钉钉发消息，默认通知渠道选「钉钉工作消息」并保存

五、验证是否成功

检查项怎么测正常表现
配置是否生效保存后刷新 IM 配置页已填项仍显示，密钥显示为 ******
签到扫码打开会议室 PAD 签到二维码 → 选钉钉登录跳转钉钉授权后能回到签到成功页
消息推送创建一条测试预定钉钉收到工作通知（需用户已绑定 dingtalk_user_id）
审批回调在钉钉里通过/驳回审批本系统预定状态同步变更
员工账号如何与钉钉对应？
首次钉钉登录时，系统会按手机号或邮箱自动匹配已有用户；匹配不上会新建账号。建议先在「用户管理」里维护员工手机号，与钉钉一致。
常见问题
• 扫码报 redirect_uri 错误 → 检查安全设置里是否加了 /checkin/ 和 OAuth 回调地址
• 收不到消息 → 检查权限是否审批通过、通知渠道是否选了钉钉、用户是否用钉钉登录过一次
• 审批不同步 → 检查事件订阅 URL 是否带 tenant_id，Token/AESKey 两边是否一致
