📋 钉钉对接配置说明

💡 重要提示：本配置需要用到两个后台，请使用同一个钉钉管理员账号登录操作。

一、两个后台地址

后台名称地址用途
钉钉开发者后台https://open.dingtalk.com/创建应用、获取凭证、配置权限和回调
钉钉管理后台https://oa.dingtalk.com/管理企业信息、OA审批、发布应用

二、需要提供的凭证信息

参数说明获取位置
CorpId企业唯一标识管理后台 → 首页 → 企业信息
AppKey应用标识开发者后台 → 应用详情 → 应用凭证
AppSecret应用密钥开发者后台 → 应用详情 → 应用凭证
AgentId应用编号开发者后台 → 应用详情
审批流程Code审批模板编码管理后台 → 工作台 → OA审批 → 模板详情

三、操作步骤

1 登录钉钉开发者后台

访问 https://open.dingtalk.com/，使用钉钉管理员账号扫码登录。

2 创建企业内部应用

  1. 点击左侧菜单 应用开发 → 企业内部应用
  2. 点击 创建应用
  3. 填写信息：应用名称（如：会议预定）、应用描述、上传图标
  4. 点击 确定创建

3 获取 AppKey 和 AppSecret

  1. 在应用详情页，点击 应用凭证
  2. 复制 AppKey
  3. 点击 AppSecret 后的 "查看"，扫码验证后复制

4 获取 CorpId

访问 https://oa.dingtalk.com/（管理后台），在页面顶部或 企业信息 中，复制 CorpId。

5 获取 AgentId

回到 开发者后台 → 应用详情页，在 AgentId 字段处直接复制。

6 创建审批模板并获取流程Code

  1. 访问 https://oa.dingtalk.com/（管理后台）
  2. 点击 工作台 → OA审批
  3. 点击 创建新模板，选择 "自定义模板"
  4. 设计审批表单（可参考下方建议字段），保存并发布
  5. 进入模板详情页，查看浏览器地址栏 URL，复制 processCode= 后面的值
📌 获取 processCode 技巧：如果详情页没有直接显示，看浏览器地址栏 URL，格式为 ...?processCode=PROC-XXXXX，复制 PROC-XXXXX 部分即可。

7 配置回调地址

  1. 回到 开发者后台 → 应用详情 → 事件与回调
  2. 设置回调URL为：https://meeting.sisuu.com/api/dingtalk/callback
  3. 设置回调事件：审批任务回调、通讯录变更通知

8 配置应用权限

  1. 开发者后台 → 应用详情 → 权限管理
  2. 搜索并申请以下权限：
    • 通讯录部门信息读权限
    • 通讯录部门成员读权限
    • 成员信息读权限
    • OA审批实例写权限
    • 企业会话消息发送权限

9 发布应用

  1. 开发者后台 → 应用详情 → 版本管理与发布
  2. 点击 创建新版本，填写版本信息
  3. 点击 发布，选择可见范围（建议全公司）
✅ 完成后：请将获取到的 CorpId、AppKey、AppSecret、AgentId、审批流程Code 提供给系统管理员进行配置。
