飞书对接配置说明

按本文操作后，员工可在签到页用飞书扫码登录，系统可推送飞书消息、同步通讯录（需权限），并对接飞书审批（可选）

开始前准备：
1. 使用飞书企业管理员账号操作
2. 在 IM 配置页顶部记下你的租户 ID（下文用 {租户ID} 表示，例如 1）
3. 系统访问地址固定为 https://meeting.sisuu.com

一、配置完成后能实现什么

功能需要填哪些项
会议室 PAD / 签到页「飞书登录」AppId、AppSecret、应用类型选「企业自建应用」+ 配置重定向 URL
预定成功、审批结果等飞书消息同上 + 通知设置选「飞书机器人消息」+ 消息与通讯录权限
预定走飞书审批再加：审批定义 Code、Verification Token（事件订阅）
群机器人查会议室（可选）Verification Token + 机器人事件订阅地址

二、IM 配置页字段对照（填什么、从哪来）

本系统字段是否必填在飞书哪里找
飞书应用 AppId 必填 飞书开放平台 → 你的应用 → 凭证与基础信息 → App ID
飞书应用 AppSecret 必填 同上 → App Secret，点击「查看」后复制
Verification Token 配事件订阅时必填 应用 → 事件订阅 里自己设定，飞书和本系统填完全相同的值（用于 URL 校验）
应用类型 必填 一般选 企业自建应用；只有从飞书应用商店安装时才选「应用商店应用」
审批定义 Code 选填 只有「预定需飞书审批」才填。飞书管理后台 → 审批 → 审批定义详情 URL 中的 approval_code

三、在飞书开放平台创建应用

1 登录并创建应用

  1. 打开 飞书开放平台，使用管理员登录
  2. 点击 创建企业自建应用
  3. 填写应用名称（如：会议室预定）、描述、图标，点击创建

2 复制 App ID 和 App Secret

进入应用 → 凭证与基础信息，复制到 IM 配置页。

3 配置重定向 URL（扫码登录必做）

应用 → 安全设置 → 重定向 URL，添加：

  • https://meeting.sisuu.com/api/oauth/callback/feishu?tenant_id={租户ID}
  • https://meeting.sisuu.com/checkin/（签到页，建议整条前缀都加上）
员工扫 PAD 二维码签到时会打开 /checkin/...，未加白名单会导致飞书授权失败。

4 申请权限

应用 → 权限管理 → 开通以下权限（开通后需发布版本才生效）：

  • contact:user.base:readonly — 获取用户基本信息
  • contact:department.base:readonly — 获取部门信息
  • im:message 或「以应用身份发消息」— 发送预定/审批通知
  • approval:approval — 发起与接收审批（仅在使用飞书审批时）

5 配置事件订阅（使用飞书审批时必做）

  1. 应用 → 事件订阅
  2. 请求地址 URL：
    https://meeting.sisuu.com/api/callback/approval/feishu?tenant_id={租户ID}
  3. 设置 Verification Token（自定义一串字符），本系统 IM 配置页填相同值
  4. 若平台要求 Encrypt Key，按飞书文档配置（本系统当前主要校验 Token）
  5. 订阅事件：approval_instance（审批实例状态变更）等审批相关事件
  6. 保存后等待「请求地址验证通过」

6 创建审批定义（可选）

  1. 飞书客户端 → 工作台 → 审批 → 创建审批定义
  2. 设计表单并发布
  3. 在审批定义详情页 URL 中找到 approval_code= 后面的编码，填到 IM 配置页「审批定义 Code」

7 发布应用

  1. 开放平台 → 应用 → 版本管理与发布
  2. 创建版本，提交发布（企业自建应用通常管理员直接通过）
  3. 在 可用性 中确保目标员工可见

四、在本系统保存配置

  1. 打开 IM 配置 → 飞书 标签
  2. 打开「启用」开关
  3. 应用类型选 企业自建应用（绝大多数情况）
  4. 填写 AppId、AppSecret；若配置了事件订阅，再填 Verification Token
  5. 点击 保存配置
  6. 在 通知设置 中，若要发飞书消息，默认通知渠道选「飞书机器人消息」

五、验证是否成功

检查项怎么测正常表现
配置保存保存后刷新页面字段保留，密钥显示 ******
签到扫码PAD 签到页 → 飞书登录飞书授权后返回签到成功
消息推送创建测试预定飞书收到应用消息
审批同步在飞书审批里操作本系统预定状态更新
员工账号如何与飞书对应？
首次飞书登录时，系统按手机号或邮箱匹配已有用户；否则自动建号。请保证「用户管理」里手机号与飞书一致。
常见问题
• 授权失败 / redirect_uri 错误 → 检查重定向 URL 是否完整、是否带 tenant_id（OAuth 那条）
• 事件订阅验证失败 → Token 与 IM 配置页不一致，或服务器未公网可访问
• 收不到消息 → 权限未发布、通知渠道未选飞书、用户未用飞书登录绑定过
• 应用类型选错 → 自建应用必须选「企业自建应用」，否则 token 接口会报错
