📋 飞书对接配置说明

一、需要提供的凭证信息

参数说明获取位置
App ID应用标识开发者后台 → 应用详情 → 凭证与基础信息
App Secret应用密钥开发者后台 → 应用详情 → 凭证与基础信息
Approval Code审批定义编码审批管理 → 审批定义详情
Verification Token事件验证Token开发者后台 → 事件订阅

二、操作步骤

1 登录飞书开发者后台

访问 https://open.feishu.cn/，使用飞书管理员账号登录。

2 创建企业自建应用

  1. 点击 创建企业自建应用
  2. 填写应用名称（如：会议预定）、应用描述
  3. 上传应用图标
  4. 点击 创建

3 获取 App ID 和 App Secret

  1. 应用详情页 → 凭证与基础信息
  2. 复制 App ID
  3. 点击 App Secret 后的"查看"，复制

4 创建审批定义并获取 Approval Code

  1. 飞书管理后台 → 工作台 → 审批
  2. 点击 创建审批，设计表单
  3. 保存并发布
  4. 在审批定义列表中，点击审批名称进入详情
  5. URL 中的 approval_code 参数即为 Approval Code

5 配置事件订阅

  1. 开发者后台 → 应用详情 → 事件订阅
  2. 设置请求网址URL为：https://meeting.sisuu.com/api/callback/approval/feishu
  3. 订阅以下事件：审批实例状态变更、通讯录用户变更、通讯录部门变更

6 配置应用权限

  1. 开发者后台 → 应用详情 → 权限管理
  2. 添加以下权限：
    • 获取通讯录部门信息
    • 获取通讯录用户信息
    • 审批实例的读写
    • 发送飞书消息

7 发布应用

  1. 开发者后台 → 应用详情 → 版本管理与发布
  2. 点击 创建版本，填写版本号和更新说明
  3. 申请发布，等待管理员审核通过
💡 提示：完成以上步骤后，请将获取到的 App ID、App Secret、Approval Code、Verification Token 提供给系统管理员进行配置。
